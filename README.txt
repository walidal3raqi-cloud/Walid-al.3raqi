طريقة النشر المجاني على GitHub Pages:
1) أنشئ حسابًا على github.com ثم مستودعًا جديدًا (Public) باسم مثل shop.
2) ارفع كل ملفات هذا المجلد (Add file > Upload files) ثم Commit.
3) من Settings > Pages اختر Deploy from a branch ثم main و /root واحفظ.
4) بعد دقيقة يظهر الرابط https://اسمك.github.io/shop/
5) افتح الرابط في Chrome على أندرويد > القائمة > تثبيت التطبيق (Install app).
لملف APK: ادخل pwabuilder.com والصق الرابط ثم Package for Android.
